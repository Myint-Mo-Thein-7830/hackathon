SafeRoom — Application Map & Reference Guide

SafeRoom is a client-side smart rental living assistant built with React, Vite, and Tailwind CSS. It helps university students and young renters evaluate housing contracts by separating Condominium rules (direct MEA meters, 2+1 deposits) from Apartment/Dormitory standards (sub-meters, 1+1 deposits).

System Architecture & Evaluation Flow

Pure client-side execution — Zero network dependencies or API keys required during evaluation.

Key Code Locations (Reference Route)

1. Domain Heuristic Engine: src/services/analyzer.js Contains analyzeStructuredLease() and the DEMO_PRESETS dataset. Evaluates deposit multiples against property-type norms, applies MEA residential tier pricing (~4.5 THB/unit) vs sub-meter rates (6–8 THB fair, 10 THB predatory), and drafts the Landlord Inquiry Copilot script.
2. Lease Questionnaire: src/components/ModeB_ListingAuditor.jsx Renders the 6 clean input fields (Property Name, Type, Base Rent, Deposit selector, Advance payment timing, and Sub-meter toggle) along with the 3 one-click preset scenario chips.
3. Pre-Screened Accommodations: src/data/mockListings.js & ModeA_RoomBrowser.jsx Stores the 4 verified Bangkok residences (Lumpini Ville Ratburana, Pracha Uthit Student Court, Ideo Sukhumvit 93, Twin Peaks Phahonyothin) with search filtering and modal scorecard inspection.

"To Change This, Start Here"

To add or modify verified accommodations: Edit src/data/mockListings.js and add a new listing object following the existing schema.
To adjust electricity consumption baselines or fair thresholds: Update MONTHLY_KWH_BASELINE or APARTMENT_FAIR_ELECTRIC_RATE in src/services/analyzer.js.
To change theme accents or styling tokens: Modify tailwind.config.js or the utility classes in src/index.css.

A Practice to Reuse

Calibrating Logic by Asset Class (Flipped Evaluation): Generic scam checkers flag any 2-month deposit or private utility bill indiscriminately. By explicitly splitting rules into Condominiums vs. Apartments, SafeRoom eliminates false positives while instantly catching predatory 10 THB/unit sub-meter markups. On future projects, always categorize inputs into domain-aware contexts before applying validation rules.

How to Run the Application

Run locally via Node.js:

npm run dev
